# SPC Accounting

Keyboard-first double-entry accounting for Mac and Windows. Your books live on a pendrive.

This repository holds the installers only. **[Download the latest version →](https://github.com/nnppss/spc-release/releases/latest)**

## Install

- **Mac:** download the `.dmg`. Pick `arm64` for Apple silicon (M1 and later) or the other one for Intel Macs. Drag the app to Applications. The first time you open it, macOS refuses because the app isn't signed: open System Settings → Privacy & Security and click **Open Anyway**. Do this again after each update.
- **Windows:** download the `.exe` and run it. SmartScreen asks once: click **More info → Run anyway**.

## The pendrive

Format the pendrive as **exFAT**. It's the only format both Mac and Windows can read and write, so the same books open on either one. Quit the app before you eject the pendrive.

## Updates

The app checks for a new version when it opens, and from **Help → Check for Updates**.

- **Windows** downloads the update and asks you to restart.
- **Mac** opens the download page. Replace the app in Applications with the new one.
